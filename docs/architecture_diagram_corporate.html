Severity Component & File Issue Discovered in Code Architectural Impact Optimized Engineering Fix
CRITICAL backend/controllers/attendanceController.js:136 Sequential for loop runs 4 DB queries per student in bulk attendance. 160 sequential DB round-trips for 40 students; latency > 3.5s; causes timeouts. Refactor to atomic Attendance.bulkWrite() with updateOne upserts in 1 round-trip.
HIGH spark_teacher/screens/AttendanceScreen.js:891 selectedButton style sets backgroundColor: '#007AFF' on all active buttons. Present, Absent, and Late all turn blue instead of Green, Red, and Orange. Isolate active styling to semantic theme colors (Green `#34C759`, Red `#FF3B30`, Orange `#FF9500`).
MEDIUM assignments.js:9 vs meetings.js:225 Duplicate endpoints: /assignments/teacher/classes & /meetings/teacher/classes. Redundant logic, tight coupling of class discovery to unrelated sub-features. Standardize under dedicated REST endpoint: GET /api/teachers/:id/classes-today.
CRITICAL attendanceController.js:59, 167 new Date(date).setHours(0,0,0,0) returns an integer timestamp in ms, NOT a Date. Type mismatch in Mongoose Date query; causes missing records or UTC timezone shift. Wrap return value: new Date(new Date(date).setHours(0,0,0,0)).
HIGH backend/routes/classes.js:22 GET /api/classes is restricted to authorize('school_admin') only. Teachers cannot list their classes directly from the classes resource. Provide teacher scope or dedicated teacher schedule endpoint.
